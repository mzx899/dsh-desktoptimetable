# 方案 · 课表折叠 / 展开

> 需求（2026-11-07，1.4.0）：课表可以收起成「只有日期和表头」的一条；
> 在课表某个位置放一个折叠按钮（用户指定「月份的右边」附近）；
> 按一下收起 / 展开，**要有过程动画**。

---

## 1. 口径（与用户确认）

| 项 | 结论 |
|---|---|
| 按钮位置 | **状态条最右侧**（「自由安排」右边）。月份格只有 58pt，塞按钮会挤 |
| 折叠后保留 | 顶栏（标题 / 周次 / 时钟）+ 状态条 + 表头（100% 档约 **173pt**） |
| 收起到哪 | **顶边不动**，从底部收上去 |
| 折叠状态 | **不落盘**：重启默认展开 |
| 动画 | 0.30s ease-out，网页 + 原生同一进度 |

## 2. 为什么这次不难

课表窗口是**常驻画布**（按「展开最大档卡片 + 四周留白」建，见
`docs/方案-课表尺寸调节.md`）。折叠只是「卡片自己变矮」：

- 窗口尺寸 / 位置**不用动** → 不会闪、不会被 webView 裁；
- 缩放上限 / 画布尺寸仍按**展开态**算（`TimetableLayout.baseCardHeight`），
  所以折叠态也能正常缩放、拖到屏幕边。

## 3. 结构

### 网页

```
.card
├── .top        顶栏
├── .status     状态条（右侧 .collapsebtn ▾/▴）
├── .gridwrap   裁切容器（overflow: hidden）
│   └── .grid   网格（表头 38 + 10 行 ×54 + 间距）
└── .ovl        课程详情（原样）
```

- 折叠只改 `.gridwrap` 的 `height`：`638 → 38`（表头）；
  表头以下的 `.tcell` / `.cell` 按 `--tt-collapse` 淡出。
- 网格内部几何一磅都不动 → 表头 / 日期列的坐标与命中不变。
- `window.ttSetCollapse(p)` 由原生每帧调用；`render()` 重建 DOM 后自动补回。

### 原生

- `TimetableLayout.collapse`（0…1）+ `collapseBodyHeight = 600`（CSS px）；
  `cardHeight` 随折叠变，`baseCardHeight` 仍是展开态。
- 卡片矩形：x 居中、**顶边 = 展开时的顶边**，高度按进度插值。
- `AppDelegate.animateCollapse`：60fps + ease-out cubic，每帧同时写
  网页和原生玻璃 / 穿透 / 图钉 / 悬停。
- 折叠态缩放：`WebCardRenderer.cardCenterInPage` 跟随折叠（中心上移）。

## 4. 交互

- 按钮：展开时 ▾，收起后 ▴，`title` 同步「收起课表 / 展开课表」。
- 折叠态点表头：**保持折叠**，直接打开那一列的日期覆盖层（2026-11 改；
  面板挂在 `.card` 上、从折叠条底下垂出来，不再先把课表展开）
  （`post('toggleCollapse', { day })` → 原生 `toggleCollapse(openDay:)`）。
- 折叠前强制 `closeDayPanel()`：`.gridwrap` 的裁切会盖掉覆盖层。

## 5. 坑（实测）

1. **按钮不能把状态条撑高**：内容高 15px；按钮视觉 18px、用 `margin: -2px 0`
   把占位压回 14px。否则整张卡片高 1px，公式 / 夹屏 / 自检（773）全对不上。
2. 按钮要登记进 `HOVERABLE`，并写等价的 `.collapsebtn.tt-hover` 规则。
3. 折叠时**网格容器裁切**，所以日期覆盖层在折叠态开不出来（见上）。
4. 折叠态下「卡片中心」上移：拖动帧 / 松手对位 / 窗口跟随都要用
   `WebCardRenderer.cardCenterInPage`，不能用展开态的 476.5。
5. 原生推状态会整树重建 DOM：折叠进度由网页侧的模块变量 + `applyCollapse()`
   保持，原生不需要重复推。

## 7. 追加修正（1.4.1）：折叠态缩放按「顶边」而不是中心

用户：「缩放之后移动结果下半部分显示不出了」。

- 折叠态缩放如果还按「卡片中心」摆，折叠条会被放到**画布中间**；
  展开时顶边不动、往下长 600pt → 底部超出画布被裁（实测 -229pt）。
- 现在折叠态缩放锁**顶边**（`cardScaleAnchorTop`）：窗口按「卡片顶边 = 屏幕锚点」摆，
  页面 translate 仍是「展开态顶边」那套 → 卡片在画布里**始终顶边对齐**，
  展开时底部一定落在画布内。
- 展开收尾再加一道保护：展开后卡片若超出屏幕，夹回可见区（正常不触发）。
- 顺带修：首次启动默认位置按「卡片在画布居中」换算（以前把卡片顶出屏幕上沿 61.5pt）。
- 回归：`--verify-collapse` 的「折叠 → 面板缩放到 112% → 展开」断言。

## 8. 追加修正（1.4.2）

- **切周 / 加课不刷新**：折叠每次都会 `closeDayPanel()`；网页
  `closePanel()` 先置 `DP.closing = true`，而 `runCloseAnimation()` 在
  「没有面板元素」时直接 return —— 标记永久为 true →
  `ttUpdate` 的整树重画被永久跳过（只走轻量路径），切周 / 加课 / 删课都不更新。
  修复：没有面板元素时立刻复位 `DP.closing / DP.closingDay` 再返回。
  回归：`--verify-week-arrow`（真实点击，100% / 113% / 折叠态）。
- **按钮**：22pt 圆角块 + CSS 折线（`⌄`/`⌃`），负 margin 保持状态条高度不变。

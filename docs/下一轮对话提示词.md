- 1.3.1 的第二轮修了「缩放比例不对 / 拖动不流畅」，**几个必须知道的坑**：
  - `pageZoom < 1` 会触发 WebKit 的最小逻辑字号（9pt），小字被撑大、卡片变高。
    所以**缩小档位用 `body { transform: scale(s) }`，只有 ≥100% 才用 pageZoom**
    （`WebCardRenderer.applyScale`）。
  - **拖动预览用 transform，但松手必须收尾**：`commitCardScale` 面板开着时调
    `finishCardScaleInCanvas` → `applyScale(_:keepingCardCenter:)`。
    不收尾 = 放大档一直是位图放大（字糊），而且 `usesPageZoom` 按 `viewScale`
    判 true、实际却是 transform → `rectScale` / 玻璃 / 命中全多乘一个系数。
  - **缩放一变 `TimetableLayout.cardRectOverride` 就必须重写**：
    `apply(scale:)` 现在会自动作废它（护栏）；`performCardScale` /
    `finishCardScaleInCanvas` 重排后写入 `968×773×scale` 的新矩形。
    过期矩形被 `DesktopWindow.move` 拿去夹屏 = 「缩放后拖不到屏幕边 /
    被顶出屏幕」。
  - 两种缩放的矩形语义不同：`rectScale`（rect → view 点）在 transform 档位是 1，
    在 pageZoom 档位是 scale；`cssPoint` 的 y 翻转用**当前窗口高度**。
    `Timetable.js` 的 `gridGeom` / `columnGeom` 要用 `window.__ttGeomScale`
    把视觉矩形还原成版式 px（覆盖层定位）。
  - 缩放必须同步：`LiveContainerView.passthroughRect`、`glassView.frame`
    （用当前容器高度，别捕获建窗时的 webHeight）、`glassView.cornerRadius`、
    图钉尺寸（`PushPinButton.scale`）。
  - 拖动中每帧只做几何；状态推送 / 复量网页矩形 / 悬停 / 写盘放到松手。
  - 缩放锚点要锁**网页卡片中心**（`WebCardRenderer.cardCenterInWindow`），
    别用取整的原生 `cardRect` 中心、也别每帧重读当前中心 —— 否则拖动会轻微抖动。
  - 拖动帧必须**串行化**：先 `applyDragScale` 让网页应用缩放，回调里再对齐窗口；
    不要先改窗口再改网页（异步错位 = 574×Δscale 的抖动）。不要给拖动加 16ms 节流
    （120Hz 屏上会顿）。
  - 拖动期间**窗口尺寸不动、位置跟着卡片中心走**（取整到整点），
    translate 只补亚像素零头（≤0.5pt）。窗口服务器会把 `setFrameOrigin`
    的小数截断到整点，零头必须由 translate 补，否则卡片中心 ±0.5~1pt 抖。
    **不要把卡片用 translate 挪到画布一侧**：画布只比最大档卡片宽 ~208pt，
    偏出去就被 WKWebView 裁掉（用户：「放到最大右边被削」）。
  - 滑杆上限 = `min(115%, currentMaxScale())`，拖动中不要回写滑杆值（会跟鼠标抢）。
  - 位置写盘用「**卡片**口径」（`saveWindowState` 会把画布偏置换算掉）：
    面板开着时卡片可能被夹在画布一侧，直接存窗口原点重启后会平移。
  - 缩放锚点**每轮松手都要释放**（`cardScaleAnchorCenter = nil`），
    新一轮缩放先 `dragWindowActive = false` 重取页面原点；
    `webCardCenterInWindow()` 优先用 `cardRectOverride`（卡片可能不在画布中心）。
  - 折叠：`TimetableLayout.collapse`（0…1）只影响**卡片高度**，`baseCardHeight`
    仍是展开态（画布 / 缩放上限不变）；卡片顶边固定、高度插值。
    `WebCardRenderer.cardCenterInPage` 要跟着折叠走（中心上移），
    拖动帧 / 松手对位别再用 476.5。
  - 折叠按钮的**占位高度**不能超过状态条内容高（15px），否则状态条长高 1px、
    整张卡片高 1px，公式 / 夹屏 / 自检（773）全对不上。现在是 22pt 视觉 + 负 margin。
  - 网页 `runCloseAnimation()` 在「没有面板元素」时必须清掉 `DP.closing`：
    否则 `ttUpdate` 的整树重画会被永久跳过 —— 切周 / 加课 / 删课都不刷新
    （折叠每次都会 `closeDayPanel()`，更容易踩到）。
  - `.gridwrap` 的裁切会盖掉日期覆盖层 → 折叠前必须 `closeDayPanel()`。
  - 折叠态缩放锚点是**顶边**（`cardScaleAnchorTop`），不是中心：
    画布只比展开卡片大一圈，折叠条要是被摆到画布中间，展开时底部一定被裁。

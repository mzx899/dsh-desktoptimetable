# 日期覆盖层 · 规格定稿

> 需求：点课表表头的日期（"周一 / 3"），在该列上覆盖一个面板，
> 显示当天课程 + 系统提醒事项（可增删改）+ 系统日历事件。

## 一、覆盖层

| 项 | 定稿 |
|---|---|
| 触发 | 点课表表头的日期格 |
| 覆盖范围 | **只覆盖课表那一列**（表头**不**被覆盖，日期/星期几照常显示） |
| 宽度（窄态） | = 课表单列宽度（约 119pt） |
| 位置 | 顶边贴着**表头格底边**，向下延伸 |
| 形状 | 顶部实、**尾部渐变**（渐隐化掉），非硬边矩形 |
| 出现 | **clip-path 自上而下揭开**（600ms）—— 不用 scaleY（会把文字压扁） |
| 收起 | **clip-path 自下而上收拢**（400ms），播完才清理 |
| 材质 | **有文字的地方接近不透明** `rgba(34,38,48,.94)` + `blur(40px) saturate(180%)`；无文字的尾巴从**同样的颜色**渐隐到透明 |
| 内容（**逐条玻璃卡片**） | 📋 **每条待办一张卡**（无待办则一张「今日无待办」的空状态卡）→ 永远一张「＋ 添加待办」的**幽灵卡** → 📅 **每条日程一张卡**（无日程则一张「今日无日程」的空状态卡）→ 🎊 **今日详情一张卡**（农历 / 节气 / 节日 / 天气 / 宜忌；**永远渲染**，连农历都拿不到才显示「暂无节日信息」） |
| 卡片样式 | 每条**独立玻璃卡片**：圆角 14px + 半透明暗色渐变底 `linear-gradient(160deg, rgba(255,255,255,.07), rgba(30,38,55,.72))` + 1px 渐变描边（蓝/紫/青，伪元素 + mask xor）+ 顶部 1px 白色高光 + 向下投影 + 左侧 2px 彩色竖条（待办青蓝 / 日程粉蓝 / 详情紫青；空状态**无**竖条）+ 内边距 `9px 9px 10px` |
| 卡片间距 | **9px**（≥ 8px） |
| 底板 | 卡片浮在一整块**压暗磨砂底板**（`.dpbody`）上；底板**接近不透明** —— 背后是彩色课表格，不能照抄参考图的透明度 |
| 空状态 / 幽灵卡 | 空状态更低调（无彩色竖条、描边更淡）；「＋ 添加待办」是**虚线边框的幽灵卡**，展开输入框时就地变高 |
| 溢出处理 | 内容装不下 → **面板内滚动**，**不截断条目**、不显示「还有 N 条」；滚轮在面板上不穿透到课表 |
| 实心区高度 | **自适应**（按内容高度定），不是固定值 |

## 一之二、表头标记

| 点 | 颜色 | 含义 | 位置 |
|---|---|---|---|
| 蓝点 | `#4f8cff` | **今天** | 星期几**右边**（现状不变） |
| 红点 | 红 | **有待办** | 星期几**左边** |
| 橙点 | 橙 | **有日程**（日历事件） | 星期几**左边** |

- 红点与橙点**可以同时显示**。
- 大小与间距和现有的蓝点**完全一样**。
- 选中的那一列（正在被查看）表头要有**高亮态**：
  **蓝色渐变底 + 外发光 + 顶部亮线**（2026-11 加固，贴近参考图的「周四 5」）。
  ⚠️ **不把它从表头行里拆出来** —— 表头格是 CSS Grid 的一格，
  拆出来会让网格对齐崩掉；只在原位加渐变和发光。
- 表头可点击的提示：**纯 hover 变色**（不加下划线、不加常驻图标）。
- 渐变区：**实心区自适应**，实心区底部往下**一直渐变到底**（覆盖层多高就渐多长）。

## 二、鼠标状态机

### 窄态（默认）

| 鼠标动作 | 效果 |
|---|---|
| 未打开时悬停 | **不打开**（打开只能靠点表头日期） |
| 点表头日期 | 在那一列打开（窄态） |
| 在第 N 列内移动 | 覆盖层在第 N 列（无缝跟随换列：旧淡出、新出现） |
| 移到别的列 | 覆盖层**跟着换到新列** |
| 移到**不在任何列**（时间列 / 状态条 / 表头区） | 淡出消失 |
| 移出整个课表 | 淡出消失 |
| 单击条目 | **打勾完成** |

### 通用

- **跟随模式**：点日期打开后进入跟随模式 —— 指针移到哪一列，覆盖层跟到哪一列。
- **换列 / 原生推状态时不能闪**：覆盖层元素跨 `render()` **复用**
  （同一个 DOM 元素，入场动画不重播）；原生每次推状态都只更新位置与内容。
- 跟随模式下移出课表 / 移到时间列 → **淡出**（底下的课表格浮上来），但**跟随模式保留**：
  指针移回某一列会继续跟着出现。
- **点当前列日期 → 关闭并退出跟随模式**：之后指针扫过任何日期都不会自己弹出来；
  想看就再点一次日期。
- **拖动课表窗口时** → 覆盖层强制收起（同时退出跟随模式 —— 拖动与看详情互斥）

## 三、覆盖层的几何

| 项 | 定稿 |
|---|---|
| 宽度 | **一列宽**（约 119pt）—— **只有这一种形态** |
| 高度 | 满列高（表头之下那一列） |
| 窄条塞不下 | **面板内滚动**（2026-11 改：不再截断条目、不再显示「还有 N 条」） |

> ⚠️ **宽态已删**（2026-11-02）。原来的「双击撑开」会把覆盖层撑成一个
> 浮在课表格上的大方块：盖住旁边的列、底边是硬边横切过课程格，
> 观感不好；而卡片化 + 面板内滚动之后，宽态也没多显示什么。
> 所以现在只有一列宽这一种形态，内容装不下就在面板里滚。

## 四、退出路径汇总

1. 移出整个课表 → 淡出消失（跟随模式保留，移回来继续出现）
2. 移到不在任何列 → 淡出消失（跟随模式保留）
3. 再点同一列的日期 → **直接关闭并退出跟随模式**
5. 拖动课表 → 强制收起（所有状态，同时退出跟随模式）

## 四之二、动画与材质（实现约束）

| 项 | 定稿 |
|---|---|
| 打开 | `clip-path: inset(0 0 100% 0)` → `inset(0)`，**600ms**，`cubic-bezier(.2,.85,.3,1)` |
| 收起 | 反向 `clip-path`，**400ms**；`.closing` 是**自成一体的状态**（不依赖 `.show`） |
| 淡出 | 摘 `show` 前先切 `visibility`（延迟 400ms），否则淡出**根本看不见** |
| 玻璃底色 | `rgba(34,38,48,.94)`（实心区与尾巴**必须完全一致**，否则交界处有台阶） |
| 模糊 | `blur(40px) saturate(180%)`（实心区与尾巴**必须一致**，否则两种材质） |
| 不透明度 | 实心区（**有文字**）接近不透明 —— 半透明时底下的课表格透上来和文字叠在一起，看不清 |
| 尾巴衰减 | 靠 **`mask-image`** —— WKWebView 里 `backdrop-filter` 会把背景渐变的 alpha 吃掉，背景渐变做不了衰减 |
| 尾巴四边 | 上下淡出 **乘上** 左右淡出（`mask-composite: intersect`）—— 只淡上下的话底部看得出一个**矩形**，像「两个模块拼接」 |
| 实心区左右 | 也要各留一条窄渐隐带（各 6%）—— 否则实心区是硬边矩形、尾巴是软的，两者放在一起仍像拼接 |
| 实心区投影 | **只往上打**（往下打会在尾巴上留下一条深色硬带） |
| 下边框 | **不要**（横在实心区 ↔ 尾巴的交界处，会把瀑布断成两截） |

## 四之三、文本输入（网页里的输入框）

| 项 | 定稿 |
|---|---|
| 桌面层窗口 | 默认 **`.nonactivatingPanel`** —— 永远不能成为 key window（不能抢用户前台焦点） |
| 后果 | WKWebView 拿不到键盘焦点 → 网页里的 `<input>` **能点开但打不了字** |
| 解法 | 输入框聚焦时网页发 `textInputFocus` → 原生把窗口**临时**变成 key（`canBecomeKey` 放开）→ 按键进网页；失焦 / 回车 / Esc 再还原 |
| 输入框元素 | **跨重绘复用同一个元素** —— 原生每推一次状态就重绘整个面板，输入框要是每次新建，用户的字和焦点全丢 |
| 点击穿透 | 窗口的 `ignoresMouseEvents` 必须**每次**按当前指针位置重算 —— 只在状态变化时改的话，鼠标快速移进卡片时那一次点击会**穿透到桌面**（「鼠标在日期上却点不动」） |

## 六、技术方案

- **覆盖层做在网页层**（CSS/JS）：网页 grid 天然知道每列精确位置（换列像素级准），
  生长/渐变/蒙版用 CSS transition 最顺；不与原生抢鼠标事件。
- **数据由原生喂**：原生查 EventKit → push 状态给网页；网页发 intent 给原生
  （查数据 / 增删改）。
- **权限弹窗**：app 是 `LSUIElement` 后台应用，请求授权时系统弹窗可能不显示
  → 照抄现有 `setActivationPolicy(.regular)` → `.accessory` 先例。
- **自动化护栏**：`AutomationMode` 下**绝不**请求 EventKit 权限、绝不碰真实日历/提醒。

### 8.1 网页 → 原生（`post(action, payload)`，复用现有 `window.webkit.messageHandlers.tt`）

| action | payload | 触发时机 |
|---|---|---|
| `datePanelOpen` | `{ "day": 1…7 }` | 点表头日期 |
| `datePanelClose` | `{ "day": 1…7 }` | 再点同一列日期（关闭） |
| `todoToggle` | `{ "day": 1…7, "index": Int }` | 单击待办条目（打勾） |
| `todoAdd` | `{ "day": 1…7, "title": String }` | 内联输入框回车 |
| `todoDelete` | `{ "day": 1…7, "index": Int }` | 长按 / 删除按钮 |

### 8.2 原生 → 网页（`window.ttUpdate(json)` 的扩展字段）

现有 `TimetableState.webJSON` 之外**新增**一个顶层字段 `dayPanel`：

```json
{
  "dayPanel": {
    "day": 3,
    "todos":  [ { "title": "买牛奶", "due": "20:00", "done": false } ],
    "events": [ { "title": "团队会议", "start": "10:00", "end": "11:30" } ],
    "festival": {
      "lunar": "农历九月初七",
      "term": "寒露",
      "festivals": ["中秋节"],
      "weather": { "text": "晴", "temperature": 12, "min": 12, "max": 21 },
      "yi": "出行",
      "ji": "动土"
    }
  },
  "dayFlags": { "1": { "todo": true, "event": false }, "2": { "todo": false, "event": true } }
}
```

- `dayPanel` 为 `null` / 缺失 → 没有待办 / 日程数据（没授权）
- `dayFlags` 驱动表头的红点 / 橙点
- `festival` 任一字段可为空字符串

#### 8.2.1 卡片化后的网页结构（2026-11）

覆盖层内容改成**逐条玻璃卡片**（不再用「分组标题 + 条目行」）：

```html
.dpbody            <!-- 压暗磨砂底板（唯一带 backdrop-filter 的一层） -->
  .dpcards         <!-- 卡片容器，纵向 flex，gap 9px -->
    .dpcard.todo   <!-- 一条待办 = 一张卡（data-todo-index 挂在这里） -->
      .dpcardhd    <!-- 标签行：📋 + 待办事项 -->
      .dpcardbody  <!-- .dpmain（圈 + 标题） + .dptime（到期时间） -->
    .dpcard.event  <!-- 一条日程 = 一张卡（.dpevt 标题 + .dpevs 起止时间） -->
    .dpcard.detail <!-- 今日详情 = 一张卡（农历 / chips / 天气 / 宜忌） -->
    .dpcard.empty  <!-- 空状态（今日无待办 / 今日无日程），无彩色竖条 -->
    .dpcard.ghost  <!-- 「＋ 添加待办」幽灵卡（虚线边框） -->
```

要点：

- **面板宽度不变**（窄态 = 单列宽，约 119pt）；
- **底板保持接近不透明**（`rgba(34,38,48,.94)` + `blur(40px)`）——
  背后是彩色课表格，不能照抄参考图的透明度；
- **卡片之间间距 ≥ 8px**（实际 `gap: 9px`）；
- **内容装不下时在面板内滚动**，**不再截断条目**、
  **不再显示「还有 N 条」**；
- 待办的**单击打勾 / 右键删除**不变（右键命中 `.dpcard.todo`）。

#### 8.2.2 `festival.weather`（天气）

| 字段 | 类型 | 说明 |
|---|---|---|
| `text` | String | 天气现象（中文，如「晴」「多云」「小雨」） |
| `temperature` | Double | 当前温度（°C），可缺省 |
| `min` | Double | 当天最低温（°C），可缺省 |
| `max` | Double | 当天最高温（°C），可缺省 |

- **`weather` 整个可以是 `null`** —— 没有城市 / 用户拒绝定位 / 网络失败 /
  用户没开「显示天气」时就是 `null`；
- 网页收到 `null`（或描述和温度都为空）→ **隐藏整行天气**，
  **绝不显示假数据**（不能出现「0°」）；
- 数据来源：**CoreLocation（系统定位）+ Open-Meteo**
  （`https://api.open-meteo.com/v1/forecast`，无需 API key）；
- **不做 IP 推断** —— 不把 IP 发给任何第三方。

#### 8.2.3 `festival.yi` / `festival.ji`（宜 / 忌）

| 字段 | 类型 | 说明 |
|---|---|---|
| `yi` | String | 宜（一条，如「出行」） |
| `ji` | String | 忌（一条，如「动土」） |

- 基于**建除十二神**（按日支循环，正建流派）**离线**计算，不联网；
- ⚠️ **这是简化的建除黄历，不是权威老黄历**，只是一个氛围提示，
  不能当择日依据（详见 `Model/AlmanacCalendar.swift` 的说明）；
- 拿不到（超出 1900–2100 支持范围）→ 空串 → 网页**隐藏这一行**。

| 全部删除 | 所有清单的全部已完成项；确认框数量**重新统计**；默认「取消」、红色「全部删除」；**≥50 条要输入「删除」**；逐条 `remove(commit:false)` + 统一 `commit()`；显示进度、防连点；部分失败如实报成功 / 失败数 |
| 写失败 | 不先移除；显示原因；保持可重试 |
| 数据接口 | `completedReminders`（**completionDate 谓词**）、`restoreReminder`、`deleteCompletedReminder`、`deleteAllCompletedReminders`（返回成功 / 失败数 + 被删 id） |
| 权限 | 沿用现有日历 / 提醒事项 FullAccess，**不新增 TCC 类型** |
| 联动 | 恢复 / 删除后 `dayPanelRevision` +1、`refreshAll()`、`loadContent(resetImmediately:false)`；网页保留当前打开天的完整缓存，避免闪烁 |

## 1. 需求时间线

### 1.1 课表图钉与拖动

**用户需求**：在课表左上角、和「我的课表」标题同一行加一个图钉。
空心（白色）表示可以拖动，实心（黑色）表示位置固定；拖动时要像系统拖动文件一样
1:1 跟随鼠标；固定后所有弹窗以课表当前位置为中心出现。

**实现结果**：

- 图钉做成两张独立形状的 template image（`pushpin-outline.png` / `pushpin-solid.png`），
  两态只有空心 / 实心区别。
- 图钉放在标题左侧、与其平行；网页顶栏预留同样的左槽，避免压住标题。
- `CardInteractionView` 负责拖动与图钉；没发生拖动的点击原样交回网页层，
  点课程、点齿轮、翻周次不受影响。
- 固定状态和窗口位置写入 `window_state.json`，重启恢复。
- 设置面板、课程编辑器、确认框、导入窗口等改由 `WindowAnchor` 以课表当前中心为锚点。
- 修复拖动位移叠加、课表可被拖出屏幕、图钉压标题等问题。

### 1.2 设置面板改成两级结构

**用户需求**：设置面板不要一条长列表，改为「板块首页 → 分类设置页」。

**实现结果**：

- 打开时是 580×152 的板块首页，四个板块砖块：外观 / 课表 / 提醒 / 系统。
- 点板块后窗口原地扩张成分类页，点「返回」收缩。
- 内容超高时在页面内部滚动，窗口不超出屏幕。
- 修复板块按钮点不中（`NSStackView` 抢命中）、返回按钮被裁掉、收缩时残留分隔线 /
  红绿灯漂移、动画中间态内容叠加等问题。

### 1.3 课程时间自定义

**用户需求**：上课时间原来是固定的，希望在「课表设置」的课表板块增加
「课程时间自定义」，做成内置滚动窗口，放在「课程预览」下面。

**实现结果**：

- 新增 `PeriodSettings` / `PeriodTime` 模型：10 节固定，默认 08:00 起；
  支持 `HH:mm`、单数字、中文冒号，失焦自动补零；校验开始早于结束、节次不重叠。
- 新增 `PeriodTimesEditor` 卡片：固定高度、内置滚动、10 行就地编辑、
  「恢复默认」按钮；合法修改写进 `settings.json` 的 `periods` 分组。
- 修改后立即应用：`Schedule.periods` 驱动时间列、课程块、状态条倒计时和提醒排程；
  `webJSON` 把作息推给 `Timetable.js`，桌面网页时间列同步更新，无需重启。
- 外层面板的内层滚动仍转发滚轮；作息列表自己滚，滚到尽头后再交给外层。

### 1.4 时间输入拆成「时 / 分」两个框

**用户需求**：数字稍微往下调一点、垂直居中；时间拆成两个框，中间的冒号不用输入。

**实现结果**：

- 每节时间由「一个 `HH:mm` 框」改成四个小框：
  `[时] : [分] – [时] : [分]`，冒号是固定标签。
- 分留空按 `00` 处理；单数字自动补零，失焦后统一显示两位数。
- 圆角背景与文字输入框分开绘制：背景 22pt 高，文字框 15pt 高并居中。
  截图逐像素核对后，数字中心与框中心对齐（默认排版会偏上约 1.5pt）。
- 焦点在同一行四个框之间移动时暂不提交，离开整行后再统一校验，
  避免改到一半被「开始晚于旧结束」弹回。

### 1.5 版本归档与更新记录
